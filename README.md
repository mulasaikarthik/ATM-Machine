ATM Machine 🏧

A simple Python-based ATM Machine simulation that allows users to securely access their account and perform basic banking operations.

Features
🔐 PIN verification
💰 Check account balance
💵 Withdraw money
➕ Deposit money
🚪 Exit the ATM
⚠️ Handles invalid inputs and insufficient balance

A beginner-friendly project that simulates the basic working of an ATM.
